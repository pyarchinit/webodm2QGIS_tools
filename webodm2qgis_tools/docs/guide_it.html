Software sperimentale, per QGIS 4. Puo' fare danni. Realizzato da Luca Mandolesi di Flyoveracademy.it. Scritto interamente con Claude Code (modelli Claude Sonnet e Opus di Anthropic). Fornito senza alcuna garanzia, uso a tuo rischio: scrive file nella cartella che scegli e puo' sovrascrivere file con lo stesso nome; puo' cambiare il CRS del progetto QGIS e aggiungere molti layer; salva la password del server nel gestore di autenticazione di QGIS. Lavora su una copia del progetto, fai un backup e usa una cartella dedicata. Non scrive nulla sul server WebODM (sola lettura).

Che cos'e'

WebODM2QGIS-tools si collega a un server WebODM (anche l'app per Windows aperta sul tuo PC) e porta in QGIS i prodotti dei task senza passare da scarica → decomprimi → importa: ortofoto, DSM/DTM, nuvole di punti, punti di scatto delle foto con apertura dell'originale, e i prodotti del plugin webodm-model-tools (nuvola scalata o georiferita, scatti e prospetti). Prima di caricare controlla EPSG, georiferimento e CRS e ti avvisa dei rischi.

Installazione

  • Serve QGIS 4 (Qt6). Non funziona con QGIS 3.
  • Da ZIP: Plugin → Gestisci e installa plugin → Installa da ZIP e scegli webodm2qgis_tools.zip.
  • Dal sorgente: copia la cartella webodm2qgis_tools in %APPDATA%\QGIS\QGIS4\profiles\default\python\plugins e attivala in Gestisci e installa plugin → Installati.
  • Compaiono il menu WebODM, la barra WebODM e il pannello a sinistra. Il pulsante Guida (nel pannello e nel menu) apre questa guida.

1. Collegarsi a WebODM

Pulsante «...» nel pannello (o menu WebODM → Collega a WebODM). Inserisci indirizzo, utente e password e premi Salva e collega. La password va nel gestore di autenticazione di QGIS (ti chiede la password principale), mai nel progetto. Per indirizzi remoti usa https: con http la password viaggerebbe in chiaro e il plugin ti avvisa.

App WebODM per Windows aperta sul PC: premi WebODM locale. Il plugin compila http://127.0.0.1:29800 (il server dell'app ascolta solo su questo computer) e controlla che sia acceso. Poi inserisci utente e password con cui entri nell'app (quelli predefiniti dell'app sono admin / admin, da cambiare). Il login e' un accesso a parte (JWT): la finestra dell'app puo' restare aperta.

2. Scegliere progetto e task

Nel pannello trovi gli elenchi Progetto e Task, oppure Scegli... per una finestra con ricerca, stato, numero di foto, anteprima e se il task e' georiferito. Si caricano solo task completati.

3. Sessione di import: nome e cartella

Al primo caricamento il plugin chiede un nome e una cartella. I file vanno in cartella\nome\task_id\..., il gruppo nel pannello Livelli prende il nome della sessione e un file sessione.json elenca cosa e' stato importato. Nome e cartella sono salvati nel progetto QGIS e si cambiano con Sessione....

4. Prodotti e semaforo CRS

Seleziona uno o piu' prodotti e premi Carica nel progetto (o doppio clic). Il pallino dice se ci sono avvisi: verde = nessuno, giallo = da leggere, rosso = serve una decisione. Il tooltip spiega perche'. I download sono in streaming su file, si possono annullare e riprendono se interrotti.

5. Avvisi su EPSG e CRS

Se c'e' qualcosa da decidere compare una finestra con le scelte. Non viene mai assegnato un CRS a caso.

Menu WebODM → Verifica CRS del progetto: elenca i layer fuori dal CRS del progetto, in gradi, senza CRS o in CRS locale.

6. Punti di scatto delle foto e originali

Il prodotto Punti di scatto delle foto crea un layer puntuale con una freccia orientata, quota, orientamento, camera, data e il campo originale (?, si, no). Per aprire la foto originale: strumento Foto (barra) — un clic mostra miniatura e dati, il doppio clic apre l'originale; oppure lo strumento QGIS «Esegui azione sull'elemento»; oppure il pulsante Apri originale.

  • Ordine di ricerca: cartella locale delle foto (se indicata), copia gia' scaricata nella sessione, server.
  • Se l'originale non e' piu' sul server il campo diventa no e lo dice, senza errori. Verifica tutti gli originali riempie il campo per tutto il task.
  • I file sopra 30 MB chiedono conferma prima di scaricarsi.

7. Foto che seguono il modello (scalato, ruotato, georiferito)

shots.geojson e' nel riferimento originale di ODM. Se hai scalato, ruotato o georiferito il modello con il plugin WebODM, per seguirlo le foto vanno trasformate con la stessa matrice. Nel gruppo Foto trovi tre prodotti:

  • Punti di scatto delle foto: riferimento originale (va con la nuvola originale). Nei task non georiferiti usa i metri locali del modello, non i gradi del file (che finirebbero a 0,0).
  • Punti di scatto – georiferiti con il plugin WebODM, EPSG:xxxx: coordinate assolute (va con la nuvola georiferita).
  • Punti di scatto – scalati e orientati con il plugin WebODM: coordinate locali, nel sottogruppo CRS locale (vanno con la nuvola scalata).

Anche la direzione delle frecce ruota con il modello. Se cambi scala o georiferimento dopo l'export, esporta di nuovo, altrimenti nuvola e foto non coincidono.

8. Scatti e prospetti del plugin WebODM

La scheda Scatti e prospetti mostra le miniature e i dati (vista, dimensione, scala 1:N, dpi, EPSG) degli scatti creati con il plugin WebODM.

  • Pianta georiferita: si carica nell'EPSG reale e si sovrappone al resto.
  • Prospetto, sezione o pianta non georiferita: il GeoTIFF ha le coordinate del piano dell'immagine in metri, non una posizione sulla Terra. Si carica con un CRS locale in un sottogruppo spento e si apre in una mappa a parte. Il file .points arriva accanto, per il Georeferenziatore di QGIS.

Posizionare uno scatto sul canvas

Con lo scatto caricato, accendi la modalita' posizionamento, clicca un punto sul canvas di QGIS: le coordinate vengono catturate (correggibili a mano) e Posiziona qui crea una copia georiferita con l'angolo in alto a sinistra sul punto, nel CRS del progetto (un file VRT leggero: nessun dato copiato, l'originale resta com'e'). Il CRS del progetto deve essere proiettato in metri. Non ruota ne' cambia la scala dello scatto.

9. Export del plugin WebODM e nuvola georiferita

Il gruppo Export del plugin WebODM elenca i file salvati con webodm-model-tools. La nuvola georiferita riceve l'EPSG scelto nella sezione Georiferimento del plugin: se nel file il CRS manca viene assegnato quello, senza bloccarti. La nuvola scalata non georiferita ha coordinate locali: va in CRS locale, spenta, a parte dalla mappa.

10. Visualizzatore WebODM dentro QGIS

Menu WebODM → Visualizzatore WebODM: vista 3D, mappa 2D o dashboard del task dentro QGIS (QtWebEngine), con login automatico. Se QtWebEngine manca si apre il browser di sistema.

11. Lingua, informazioni e avvertenze

Lingue: italiano, inglese, francese, tedesco, spagnolo, portoghese. Si sceglie in Informazioni → Lingua (automatica = lingua di QGIS) e vale al prossimo avvio. Questa guida e' in italiano e in inglese.

Limiti noti

  • Una sessione puo' contenere piu' task, scelti uno dopo l'altro.
  • Lo streaming dell'ortofoto richiede la password salvata nel gestore di autenticazione di QGIS (non scrive token nel progetto).
  • Le mesh OBJ texturizzate si scaricano e si decomprimono ma QGIS non le mostra: usa il visualizzatore 3D di WebODM.
  • La nuvola di punti si apre con il provider pdal di QGIS, che indicizza il file in background.
  • Provato su QGIS 4.2 e su un finto server WebODM; il visualizzatore web con scheda grafica non e' stato verificato in automatico.
